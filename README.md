📊 Projeto Dashboard Power BI – Análise de Dados
📌 Visão Geral

Este projeto tem como objetivo a criação de um dashboard interativo no Power BI, permitindo a análise visual de dados para apoio à tomada de decisão.
O dashboard consolida informações relevantes, aplica boas práticas de Business Intelligence (BI) e facilita o acompanhamento de indicadores (KPIs).

🎯 Objetivos do Projeto

Transformar dados brutos em informações visuais e estratégicas

Criar indicadores-chave de desempenho (KPIs)

Facilitar a análise de tendências, comparações e resultados

Apoiar decisões operacionais, táticas e estratégicas

🛠️ Ferramentas Utilizadas

Power BI Desktop

Power BI Service (publicação e compartilhamento)

Power Query (tratamento e transformação de dados)

DAX (criação de medidas e KPIs)

Excel / Fonte de Dados (base de dados utilizada)

📈 Principais Recursos do Dashboard

Gráficos de linha, barra e coluna

Cartões de KPIs

Filtros interativos

Dicas de ferramentas (Tooltips)

Análise de tendências e magnitudes

Organização visual focada em clareza e usabilidade
